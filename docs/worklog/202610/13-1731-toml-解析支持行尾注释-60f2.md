# 20261013-1731-toml-解析支持行尾注释-60f2：TOML 解析支持行尾注释

> **创建**：2026-10-13 17:31:59（@GuoJia-Agent）

## 背景

用户转述另一 Agent 的排查：`groups = ["base"] # 尾注释` 在 rulemux 中解析失败，报
`references undefined file group "\"base\"] # 尾注释"`，而标准 TOML（tomllib）解析正常。

已核实属实（`internal/config/config.go`）：

- `config.go:154` 整行注释只判 `strings.HasPrefix(line, "#")`，行尾注释不进这个分支；
- `config.go:199` `val := strings.TrimSpace(line[idx+1:])` 把 `=` 后所有内容（含注释）当值；
- `parseArray` / `unquote` 无剥注释步骤 ⇒ 注释被吃进组名。
- **额外发现（比报告更严重）**：`config.go:159` 表头判定要求 `HasSuffix(line, "]]")`，
  `[[source]] # 注释` 会落进 `config.go:189` 的 `cur = curNone` ⇒ **整张表被静默忽略**。
- 旁证：`internal/cmd/init.go` 生成的示例配置本身就用 `path = ["a.md"]  # 注释` 风格教学
  （写在整行注释里，用户取消注释即触发）。

## 待办

- 无（本任务自包含：改解析器 + 回归测试 + 文档同步）。

## 下一步

在 `internal/config/config.go` 加引号感知的 `stripTrailingComment`，在 `Load` 循环每行
（`strings.TrimSpace` 之后）剥一次，覆盖键值与表头两类场景；然后加回归测试、更新
`docs/design/implementation.md` §6。

## 过程

- 定位（HEAD revision，行号为改动前）：`internal/config/config.go:154` 整行注释只判
  `HasPrefix(line, "#")`；`config.go:199` `val` 吃下 `=` 后全部内容；`config.go:159`
  表头判定 `HasSuffix(line, "]]")` 对带尾注释的表头失效 ⇒ 落入 `config.go:189`
  `cur = curNone`，整张表静默丢失。
- 改法（行级一次剥离，单点覆盖两类场景）：
  - `Load` 循环 `line := strings.TrimSpace(sc.Text())` 之后插入
    `line = stripTrailingComment(line)`，在空行/整行注释/表头判断**之前**执行；
  - 新增 `stripTrailingComment`（放 `unquote` 旁）：按单/双引号状态扫描，剥掉字符串外
    第一个 `#` 及其后内容；引号内的 `#`（如 `path = "/rules/a#b.md"`）不剥。
    shortcut 注释已注明：不处理 TOML `\"` 转义（本解析器其余各处同样不处理）。
- 选行级而非值级的原因：值级要改 `parsePaths`/`parseArray`/`unquote`/`scope` 多个取值点
  且仍漏表头；行级只加一行调用，一处覆盖全部，与既有判断顺序天然兼容。
- 回归测试（`internal/config/config_test.go`）：
  - `TestTrailingComment`：端到端——`[[file_group]] # 注释` 表头、`groups = ["base"] # c`、
    `scope = "user"# 无空格`、`path = '/rules/a#b.md'`（引号内 `#` 保留）均正确；
  - `TestStripTrailingComment`：8 个用例单测引号状态机，含注释里的引号（`# don't panic`）。
- 验证：`gofmt -l` 干净；`go build ./...` / `go vet ./...` / `go test ./...` 全绿
  （新用例先单跑通过，再全量通过）。
- 附带发现：`docs/design/implementation.md` §6 示例里本来就有一行
  `workspace = [...] # 只在这两个工作区生效`——该示例在修复前是坏的，现已真实可用。

## 结论

已修复：解析器支持行尾注释（键值 + 数组表表头两类场景），引号内的 `#` 受保护，
整行注释行为不变。零新增依赖。回归测试两枚 + 设计文档 §6 同步。
未做（明确 YAGNI）：多行数组 / 转义序列 / 内联表等完整 TOML 语义。
遗留风险：含 `\"` 转义且带 `#` 的极端值不在支持范围（shortcut 注释已标注）。
